Mencari Ide

Mengamati masalah di sekolah

Absensi manual lambat, bisa "titip absen", dan rekapnya harus diketik ulang. Kelompok membandingkan beberapa ide:

IdeKelebihanKekurangan
Absen QR codeMudahBisa difoto & dititipkan
Absen sidik jariAkuratButuh alat khusus, mahal
Absen wajah via kamera dipilihTidak bisa dititipkan, cukup HPPerlu belajar AI

Target: daftar wajah → absen otomatis → rekap bisa diunduh → bisa diakses dari HP.

📚

Riset & Belajar

Sebelum ngoding, cari tahu dulu

  • Cara komputer mengenali wajah: deteksi posisi wajah → ubah jadi angka (descriptor) → bandingkan jaraknya.
  • Library: OpenCV (Python) untuk prototipe, face-api.js (JavaScript) untuk versi web.
  • Hosting gratis: Vercel, Netlify, GitHub Pages → dipilih Vercel.
  • Sumber belajar: YouTube, dokumentasi resmi, dan asisten AI.

Prototipe Awal: Python + OpenCV

Versi pertama di laptop

capture_faces.py   → ambil 50 foto wajah dari webcam
train_model.py     → latih model LBPH dari foto
absen.py           → kenali wajah, tulis ke CSV

Dijalankan lewat terminal VS Code: pip install -r requirements.txt lalu python absen.py. Wajah anggota dikenali ✅.

⚠️ Masalah: hanya jalan di laptop ber-Python, tidak bisa dibuka dari HP, dan tidak bisa di-hosting di Vercel (butuh server hidup terus). → Pindah ke web!

Coding Web di VS Code

HTML + CSS + JavaScript + face-api.js

  1. index.html — kerangka: splash, navbar, 5 halaman, footer.
  2. styles.css — variabel warna, grid, animasi, media query HP.
  3. Unduh face-api.js + 3 model ke vendor/ (tidak bergantung CDN).
  4. app.js — splash & muat model → routing → kamera → daftar wajah (15 sampel) → absensi (FaceMatcher, konfirmasi 3 frame, suara) → rekap & CSV → tema & notifikasi.
  5. Tes langsung dengan Live Server di http://127.0.0.1:5500.
Deteksi wajah→ Landmark 68→ Descriptor 128 angka→ Bandingkan (jarak < 0.5)→ Tercatat ✅

Deploy ke Vercel

Dari GitHub → online dalam hitungan menit

Buat vercel.json (sajikan folder public, izinkan kamera, cache model). Lalu vercel.com/new → Import repo → Framework Other → Deploy. Atau dari Termux:

pkg install nodejs-lts git -y
npm i -g vercel
git clone https://github.com/HOOOOOOQ/opencv.git && cd opencv
vercel login
vercel --prod

✅ Hasil: https://opencv-alpha.vercel.app — HTTPS otomatis, kamera jalan di HP.
