Latar Belakang & Masalah Awal

Project awal: Python + OpenCV (LBPH) di desktop

Versi pertama berupa program Python (absen.py, face_engine.py) yang membuka kamera lewat jendela OpenCV. Masalahnya:

  • ✕ Butuh server Python yang terus hidup → tidak bisa di-hosting di Vercel.
  • ✕ Hanya jalan di komputer yang terpasang Python.
  • ✕ Tampilan belum modern, belum ada splash loading.

Keputusan: bangun ulang agar 100% berjalan di browser — tanpa server — supaya bisa dibuka dari HP mana saja.

Splash Loading

Layar pembuka sambil memuat model AI

Saat web dibuka, tampil logo + judul + progress bar. Di balik layar, 3 model dimuat berurutan:

① Tiny Face DetectorMenemukan posisi wajah di gambar
② Landmark 68 (tiny)Titik mata, hidung, mulut — untuk meluruskan wajah
③ Face RecognitionMengubah wajah jadi 128 angka (descriptor)

Setelah 100% → splash menghilang dengan animasi dan dashboard tampil.

Daftar Wajah

Merekam identitas wajah ke perangkat

Isi nama & kelas→ Kamera nyala→ Deteksi wajah→ Ambil 15 sampel→ Simpan ke localStorage
  • kuning wajah terlalu jauh → "Dekatkan wajah".
  • hijau oke → tiap ±0,35 detik 1 sampel disimpan (ada efek kilat & progress bar).
  • Disimpan: { nama, kelas, 15 descriptor, foto thumbnail }.

Absensi Otomatis

Inti sistem — mengenali & mencatat

  1. Setiap frame kamera → semua wajah dideteksi → dihitung descriptor-nya.
  2. Dibandingkan dengan data terdaftar memakai jarak Euclidean (ambang 0.5). Makin kecil jarak, makin mirip.
  3. Agar tidak salah kenal, nama harus konsisten 3 frame berturut-turut → status Memastikan.
  4. Cocok → kotak hijau, dicatat sekali per hari, bunyi beep, notifikasi, dan suara "Nama, terabsen".
  5. Tidak terdaftar → Tidak dikenal.

Konfigurasi Vercel

File vercel.json

{
  "outputDirectory": "public",
  "cleanUrls": true,
  "headers": [
    { "source": "/(.*)",
      "headers": [{ "key": "Permissions-Policy", "value": "camera=(self)" }] },
    { "source": "/vendor/(.*)",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }] }
  ]
}
  • Memberi tahu Vercel: tidak perlu build, cukup sajikan folder public.
  • Mengizinkan akses kamera & menyimpan cache model agar loading berikutnya cepat.

Deploy ke Vercel

Dari GitHub → online dalam hitungan menit

Push ke GitHub→ Import di Vercel→ Vercel baca vercel.json→ HTTPS otomatis→ 🌐 Online

Bisa lewat website vercel.com/new atau dari Termux:

pkg install nodejs-lts git -y
npm i -g vercel
git clone https://github.com/HOOOOOOQ/opencv.git && cd opencv
vercel login
vercel --prod

Hasil: https://opencv-alpha.vercel.app ✅

Subdomain Sendiri

kel2.pallrzki.my.id

  1. Vercel → Settings → Domains → tambah kel2.pallrzki.my.id.
  2. Di DNS pallrzki.my.id tambahkan record:
TypeNameValue
CNAMEkel2cname.vercel-dns.com

Tunggu propagasi DNS → web bisa dibuka di https://kel2.pallrzki.my.id.
